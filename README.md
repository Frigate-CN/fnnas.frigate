## Frigate fnOS Plugin

A dedicated plugin for quickly installing Frigate on Flyme OS, featuring wizard-based rapid configuration.

Note: This plugin is not officially developed by Frigate.

## Localization

User visible text is provided through the `i18n/` directory. `i18n/en-US` is required and `i18n/zh-CN` provides the Simplified Chinese translations. `manifest`, `app/ui/config` and the `wizard/*` files reference the translated strings with `${section.key}` placeholders, so both locale files must always define the same sections and keys.
